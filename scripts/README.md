# Post-processing Scripts

## fix-exact-optional-properties.js

This script fixes compatibility issues with `exactOptionalPropertyTypes: true` in files generated by OpenAPI Generator.

### Problem

OpenAPI Generator for TypeScript doesn't support strict optional property typing (`exactOptionalPropertyTypes: true`). This leads to TypeScript errors when assigning values that might be `undefined` to optional properties.

### Solution

The script automatically modifies the `Configuration` class constructor in `src/generated/configuration.ts`, replacing direct assignments with conditional checks:

```typescript
// Before:
this.apiKey = param.apiKey;

// After:
if (param.apiKey !== undefined) {
    this.apiKey = param.apiKey;
}
```

### Usage

The script runs automatically when executing `npm run generate-client` and is integrated into the package build process.

### Automatic Execution

The script is integrated into the following commands:
- `npm run generate-client` - client generation + fix
- `npm run prepublishOnly` - full preparation for publishing

This ensures that `exactOptionalPropertyTypes` issues are automatically fixed on every code generation.
